## 📌 Objective

Build a temperature converter website where the user inputs a temperature in either Fahrenheit or Celsius and presses a "Convert" button. The converted temperature is then displayed with the correct unit. The UI includes an input field, dropdown menu, convert button, and display area.

---

## ✨ Features

- Input field with number validation
- Dropdown to select input unit (Celsius, Fahrenheit, Kelvin)
- Convert button + Enter key support
- Live conversion as user types
- Results shown for all 3 units simultaneously
- Color coded result cards
- Conversion formula shown after each conversion
- Quick reference cards (Boiling, Freezing, Body Temp, Absolute Zero)
- Error message for invalid input
- Fully responsive — mobile, tablet, desktop
- Dark theme design

---

## 🧮 Conversion Formulas

| From | To Celsius | To Fahrenheit | To Kelvin |
|---|---|---|---|
| Celsius | — | (°C × 9/5) + 32 | °C + 273.15 |
| Fahrenheit | (°F − 32) × 5/9 | — | (°F − 32) × 5/9 + 273.15 |
| Kelvin | K − 273.15 | (K − 273.15) × 9/5 + 32 | — |
